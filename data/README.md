# Контуры суши

`ne_110m_land.geojson` содержит полигоны суши Natural Earth масштаба 1:110 000 000. Файл хранится в исходном виде и используется локально. Из-за масштаба часть небольших островов и деталей береговой линии отсутствует.

- [Файл Natural Earth Vector v5.1.2](https://github.com/nvkelso/natural-earth-vector/blob/v5.1.2/geojson/ne_110m_land.geojson)
- [Условия использования Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/) помещают данные в общественное достояние.
