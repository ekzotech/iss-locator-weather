# МКС и погода под ней

Сервис раз в минуту сохраняет координаты МКС и модельную погоду в точке под станцией, если она над сушей. Страница на русском языке показывает последнюю точку, недавнюю траекторию и историю наблюдений. Доступ к истории сохраняется при сбое провайдеров.

## Архитектура

- Отдельный процесс сбора на Mojo::IOLoop. Веб-процессы читают SQLite и не запускают сбор. В разработке и тестах можно запустить один цикл вручную.
- Open Notify поставляет координаты и Unix-время. Open-Meteo поставляет температуру в °C, общую облачность в процентах, код WMO и время модельных данных. Используем `cell_selection=nearest` для запроса в точке под станцией.
- Упрощённые полигоны суши Natural Earth используются и для классификации, и для карты. Острова и береговая линия ограничены масштабом данных. Поиск названия ближайшего города не требуется для запроса погоды над сушей.
- Статусы наблюдения: погода получена, над водой, погода недоступна. При сбое координат сохраняем предыдущую историю. Время наблюдения и время модели храним отдельно.
- HTML рендерится на сервере. JavaScript обновляет карту и историю через API приложения. Интерфейс начинается с мобильной компоновки и расширяется на широком экране.

## Работа с коммитами

План — первый коммит. Для каждой пронумерованной задачи сделать один содержательный коммит с идентификатором задачи в сообщении. Сначала выполнить указанную проверку, затем дать субагенту отдельное ревью diff. Исправления включить в тот же коммит. К следующей задаче переходить после закрытия предыдущей. Не делать пустых коммитов и не размножать коммиты механическим форматированием.

План и 80 задач дают 81 коммит. Для отображения в профиле GitHub нужен email автора, связанный с аккаунтом, и попадание коммитов в ветку по умолчанию отдельного репозитория. Использовать прямую публикацию main, fast-forward или merge commit, сохраняющий исходные коммиты. Squash объединяет историю задач в один коммит.
